# SEC-POL-001: Information Security and Acceptable Use Policy

**Policy Code:** SEC-POL-001  
**Version:** 3.0  
**Effective Date:** 2026-01-01  
**Target Audience:** EMPLOYEE, HR_ADMIN, HR_REVIEWER, IT_ADMIN, SYSTEM_ADMIN  
**Scope:** All Departments, All Locations  

---

## 1. Information Security Mandate
All corporate personnel must adhere to our zero-trust security architecture and safeguard company intellectual property, customer data, and source code.

## 2. Key Security Obligations
- **Multi-Factor Authentication (MFA):** Mandatory hardware security key or authenticator app for all corporate single sign-on logins. SMS MFA is disallowed.
- **Data Classification:** Confidential and Restricted source code or customer data must never be stored on personal devices or public cloud drives.
- **Clean Desk & Screen Lock:** Systems must auto-lock after 5 minutes of inactivity. Badge access must never be shared or piggybacked.

## 3. Acknowledgement Requirement
- Completion and formal digital acknowledgement of SEC-POL-001 is a strict prerequisite before IT unlocks access to corporate GitHub repositories, Jira instances, and internal cloud consoles.
- Failure to acknowledge within 3 days of joining triggers automatic access revocation and escalation to the Chief Information Security Officer (CISO).
